# Sample outputs

Reports generated by the platform, kept as static HTML so the rendering can be
inspected without running anything.

| File | What it shows |
|---|---|
| `job_demo_report_sample.html` | a single-stock report: charts, comparison tables, sources and gaps |
| `job_demo_report_sample_preview.png` | first-screen preview of the same report |
| `beautiful_finance_report_v2.html` | a market report with the full editorial layout |
| `job_demo_report_sample_spec.json` | the report payload (facts → sections) behind the sample |

Notes:

- dates and numbers are point-in-time and were produced from the configured data
  provider; nothing is redistributed;
- the HTML is self-contained (inline styles, embedded chart images) and can be
  opened directly in a browser;
- the JSON shows the platform-owned layout: the agent supplies facts, not design.
