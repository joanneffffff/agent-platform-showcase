# Security

This repository is documentation, samples and a small code slice — it contains
**no credentials and no runnable service**.

- Sample reports are point-in-time output; they contain no personal data.
- `examples/charts/` is a code excerpt; it reads no configuration and calls no
  network endpoints.
- The runnable platform lives in a private repository and reads credentials from
  the environment only.

If you find a leaked credential here, please open a private security advisory
instead of a public issue.
